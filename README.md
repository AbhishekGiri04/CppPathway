## 🧭 About

**CppPathway** is a structured C++ learning repository built with one goal — **understand C++, don't just write it.**

Every file follows a simple pattern:

> 💡 Understand the concept → 🧠 Break down the logic → 💻 Write clean code → ⚠️ Handle edge cases

---

<div align="center">

## 💡 Sample Code

```cpp
// 05_if_else.cpp — Control Flow
#include <iostream>
using namespace std;

int main() {
    int age;
    cout << "Enter your age: ";
    cin >> age;

    if (age >= 18)
        cout << "You are eligible to vote." << endl;
    else
        cout << "You are not eligible to vote." << endl;

    return 0;
}
```

## ⚡ Quick Start

```bash
# 1. Clone the repo
git clone https://github.com/abhishekgiri04/CppPathway.git
cd CppPathway

# 2. Compile & run
g++ -std=c++17 -Wall 01_main.cpp -o output && ./output
```

**Install compiler if needed:**

```bash
brew install gcc        # macOS
sudo apt install g++    # Ubuntu / Debian
g++ --version           # verify
```
