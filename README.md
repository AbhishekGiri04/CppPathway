## 🚀 About

A structured C++ learning repo — from basics to OOP, STL, DSA, and competitive programming. Every concept is explained with logic-first approach, clean code, and real-world examples.

---

## 📂 Files

| File | Topic |
|------|-------|
| `01_main.cpp` | Hello World |
| `02_variables.cpp` | Variables & Data Types |
| `03_datatypes.cpp` | Data Types deep dive |
| `04_inputs.cpp` | cin / cout / user input |
| `05_if_else.cpp` | if / else / control flow |

> More files coming — loops, functions, arrays, OOP, STL, DSA.

---

## ⚙️ Run Any File

```bash
g++ -std=c++17 -Wall filename.cpp -o output
./output
```
